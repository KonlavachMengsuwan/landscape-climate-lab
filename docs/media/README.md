# Project media

These screenshots were captured from the functioning Landscape Climate Lab interface on 6 September 2026, at 1363 × 936 pixels.

The capture browser had WebGL disabled. The images therefore show the app's genuine SVG compatibility renderer: the same 3D scene, controls, raycast analysis and temperature model, with simplified lighting and no rendered shadows. The visible compatibility badge identifies that mode. These are not generated concept images. The regular WebGL view supports rendered shadows.

- `overview.jpg`: original layout, orbit view, 21 June at 15:00 (UTC+2).
- `walk-view.jpg`: ground-level view, 21 June at 09:00 (UTC+2).
- `temperature-morning.jpg`: temperature map at 09:00; selected cell 45.
- `temperature-map.jpg`: temperature map at 15:00; selected cell 57.
- `walkthrough.mp4`: captioned 24-second sequence of the four actual screenshots, not a continuous screen recording.
- `walkthrough.gif`: compact animated overview using the same four captures.

The two temperature captures use the original design and the same weather assumptions: air 30 °C, wind 2 m/s, RH 50%, terrestrial evaporation availability 60%. They compare independent equilibrium states, not a transient warming simulation.
